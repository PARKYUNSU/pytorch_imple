# Education

OpenAI 및 HuggingFace 등 다양한 AI 모델을 활용하는 예제를 정리한 섹션입니다.
텍스트 생성, 음성 인식, 이미지 생성 등 여러 주제를 포함하고 있습니다.

### 1. OpenAI Playground & API 활용

| 파일명                                                     | 간단 설명                                                                                     |
|:---------------------------------------------------------|:-------------------------------------------------------------------------------------------|
| **[playground_api]()**                      | OpenAI Playground API를 사용해 텍스트 생성 모델을 실험하는 기본 예제입니다.                     |
| **[ChatGPT_API]**                         | ChatGPT API를 이용한 대화형 AI 구현 예제입니다.                                               |
| **[연애상담봇]**                            | ChatGPT를 활용해 연애 상담 챗봇을 구현한 예제입니다.                                          |
| **[Code_Interpreter]**                    | ChatGPT Code Interpreter 플러그인을 활용하여 데이터 분석 작업을 수행하는 예제입니다.            |
| **[file_search]**                         | OpenAI Embeddings를 활용하여 파일 내 검색 기능(세멘틱 검색 등)을 구현하는 예제입니다.          |
| **[Embedding]**                           | OpenAI Embeddings API를 활용한 문서 벡터화 및 유사도 측정 예제입니다.                          |
| **[OpenAI_API를_이용한_서비스개발]**         | OpenAI API를 활용하여 간단한 웹/백엔드 서비스로 확장하는 과정을 다룬 예제입니다.               |

### 2. HuggingFace 모델 연동

| 파일명                                                                           | 간단 설명                                                                                           |
|:-------------------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------|
| **[허깅페이스_이용한_AI_모델_가져와쓰기]**                      | HuggingFace에서 제공하는 사전학습된 모델을 로드해 활용하는 방법을 다룹니다.                             |
| **[HuggingFace_Embedding(gpe_m3)]**                              | HuggingFace 임베딩 모델(gpe_m3)을 사용하여 텍스트 임베딩/유사도 계산을 수행하는 예제입니다.              |
| **[HuggingFace_Embedding(efs_gpe)]**                             | HuggingFace 임베딩 모델(efs_gpe)을 활용한 또 다른 임베딩/검색 예제입니다.                              |

### 3. 멀티모달 & 생성 모델

| 파일명                                                  | 간단 설명                                                                    |
|:------------------------------------------------------|:--------------------------------------------------------------------------|
| **[GPT4V]**                            | GPT-4 Vision(이미지 인식 기능)을 활용하는 간단 예제입니다.                      |
| **[TTS]**                              | Text-to-Speech(TTS) 기능을 활용해 텍스트를 음성으로 변환하는 예제입니다.         |
| **[ChatGPTWhisper_음성회의록]**         | ChatGPT Whisper 모델을 사용해 음성 회의록(스피치 투 텍스트)으로 변환하는 예제입니다. |
| **[Dalle_이미지_생성_일러스트]**         | DALL-E 모델을 통해 텍스트로부터 이미지를 생성하는 예제입니다.                   |

| **[Whisper_API_example]**              | Whisper API를 활용하여 음성을 텍스트로 변환하는 기본 예제입니다.                |
